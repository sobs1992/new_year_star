# Новогодняя звезда

Прошивка для ESP32-C5 внутри новогодней звезды: звезда играет музыку, светится в такт ей и
может включаться сама, когда кто-то подходит.

- **Музыка:** MP3-файлы из собственного флеша (плейлист с повторами и паузами) или
  интернет-радио с названием текущей песни.
- **Трансляция с телефона:** DLNA (Android), AirPlay 1 (iPhone, Mac), Spotify Connect.
- **Цветомузыка:** лента WS2812 (до 300 светодиодов) следит за громкостью; один цвет или RGB,
  где цвет зависит от того, что громче — басы, середина или верха.
- **Датчик присутствия:** радар 24 ГГц включает музыку, когда к звезде подходят.
- **Веб-страница настроек:** в собственной Wi-Fi-сети звезды и в домашней сети
  (http://star.local).

## Железо

| Что | Подключение |
|---|---|
| Seeed Studio XIAO ESP32-C5 (8 МБ флеша, 8 МБ PSRAM) | — |
| I2S-усилитель MAX98357 + динамик | BCLK — D9, LRC — D10, DIN — D8 |
| Лента WS2812 | данные — D7 |
| Радар Seeed 24GHz mmWave for XIAO | его TX — D2, его RX — D3 |

Все пины перечислены в [`main/board.h`](main/board.h).

## Сборка и прошивка

Нужен [ESP-IDF](https://docs.espressif.com/projects/esp-idf/) 6.1.

```sh
idf.py build
idf.py -p /dev/ttyACM0 flash          # первый раз: загрузчик, таблица разделов, прошивка
idf.py -p /dev/ttyACM0 app-flash      # потом: только прошивка
```

Ни одна из этих команд не трогает настройки и треки; пустой раздел для треков прошивка
форматирует сама при первом запуске.

`set_env.sh` подключает ESP-IDF из `~/esp/esp-idf` и выбирает порт платы автора: для другой
платы поменяйте в нём `ESPPORT` или передавайте `-p`.

Треков в репозитории нет. Их можно загрузить с веб-страницы, а можно положить MP3 в
`assets/tracks` и записать их на плату командой `idf.py storage-flash` (она стирает треки,
загруженные со страницы).

## Первый запуск

1. Подключитесь к открытой Wi-Fi-сети **NewYearStar**: телефон сам откроет страницу настроек.
2. Укажите домашнюю сеть — после этого страница доступна и по адресу http://star.local.
   В домашней сети звезду видят приложения для DLNA, AirPlay и Spotify.
3. На странице можно задать пароль для сети NewYearStar.

Spotify Connect работает с аккаунтом Premium и требует ключей своего приложения с
[developer.spotify.com/dashboard](https://developer.spotify.com/dashboard): страница настроек
подсказывает, где их взять.

**Кнопка BOOT:** короткое нажатие — следующая радиостанция, удержание 5 секунд — сброс к
заводским настройкам. **Жёлтый светодиод** на плате мигает кодом ошибки, расшифровка — на
странице настроек.
